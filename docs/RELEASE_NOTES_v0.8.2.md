# VecTools v0.8.2

- **Export > Print (.3mf, 2 parts)**: one 3MF object with body + plate as components, aligned and laid on the bed. Open in Bambu Studio / OrcaSlicer / PrusaSlicer and assign a filament per part; no manual alignment (importing two STLs one by one re-centres each file).
- 0.8.1: cache-proof module loading (`?v=` on every import) and a no-cache launcher (`serve.py`).

Run: `RUN_VecTools_v0.8.2.bat`, or online at https://kumodot.github.io/VecTools/
