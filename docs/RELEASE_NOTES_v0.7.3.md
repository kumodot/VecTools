# VecTools v0.7.3

- Print plate **One piece** (0.7.2): isolated plate pieces are joined to their nearest neighbour with struts, so a Contour plate always prints as a single part.
- **Extra links** + **Link spacing** (0.7.3): redundant struts along every shared edge up to a chosen gap length, so the structure is not hanging on one bar per gap.
- **Project name** field in the top bar (0.7.1): names the `.vtools` and every export.

Run: `RUN_VecTools_v0.7.3.bat`, or online at https://kumodot.github.io/VecTools/
