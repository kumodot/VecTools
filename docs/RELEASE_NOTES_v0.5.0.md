# VecTools v0.5.0

- **Supersampled PNG capture**: new *Supersample* slider (1x-4x). The frame is rendered at N times the output size in tiles and box-filtered down, so 4x = 16 samples per pixel: no more jaggies on the saved PNG, at any output size. Progress in the status bar.
- **Orbit environment**: checkbox + speed (°/s) keep the HDR turning so reflections travel over the metal. The Rotation slider follows, projects save the angle, capture pauses the spin.

Run: `RUN_VecTools_v0.5.0.bat`, or online at https://kumodot.github.io/VecTools/
