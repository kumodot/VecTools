# VecTools v0.8.0

- **Strut brush**: *Draw struts* in the Print plate group. Draw on the plate in the 3D viewport: left button adds a strut, right button cuts the plate, *Brush width* sets the size, Undo / Clear / Esc. Strokes are saved in the project and combine with the automatic struts.
- 0.7.4: automatic struts reach further by default (*Extra links* 14), so text and frame get linked all around.

Run: `RUN_VecTools_v0.8.0.bat`, or online at https://kumodot.github.io/VecTools/
