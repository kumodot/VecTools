# VecTools v0.7.1

- **Project name** field in the top bar, next to *Save project*: pre-filled with the image name, editable any time (a typed name sticks across new images; clear it to go back to auto). It names the `.vtools` file and every export (SVG, DXF, STL, OBJ, PLY, PNG, print zip), is saved in the project and shows in the window title.
- v0.7.0: print plate as a separate part (Contour with gap bridging / hollow areas, Convex hull, Box) and Export > Print zip.

Run: `RUN_VecTools_v0.7.1.bat`, or online at https://kumodot.github.io/VecTools/
